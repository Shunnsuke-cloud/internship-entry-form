# インターンシップ エントリーフォーム

Figmaのスクリーンショットをもとに作成したReact + TypeScript + Viteのフォームです。

## 実装内容

- スクリーンショットに近いフォームレイアウト
- PC・スマートフォン対応
- 必須項目の入力チェック
- フリガナの全角カタカナチェック
- メールアドレス形式チェック
- 電話番号の桁数チェック
- GitHub URLチェック
- エラー項目の赤枠表示
- 項目名の横にエラーメッセージ表示
- 最初のエラー項目まで自動スクロール
- 確認画面
- 入力内容リセット

## 起動方法

```bash
npm install
npm run dev
```

表示されたURL（通常は http://localhost:5173 ）をブラウザで開いてください。

## APIへ送信する場合

`src/App.tsx` の確認画面にある次の処理を、fetchやaxiosによるAPI通信へ置き換えてください。

```tsx
onClick={() => alert("送信処理のサンプルです。実際のAPIに接続してください。")}
```
